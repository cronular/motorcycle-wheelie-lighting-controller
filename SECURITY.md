# Security Policy

## Supported versions

Only the latest GitHub release receives security fixes.

## Reporting a vulnerability

Please use GitHub's **Security → Report a vulnerability** private reporting flow
instead of opening a public issue. Include the affected firmware version,
reproduction steps, impact, and any suggested mitigation.

Do not include Wi-Fi credentials, device identifiers, or other private data in a
public issue. Safety-relevant output behavior should also be reported privately
until a fix is available.
